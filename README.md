# Notes Backend

Backend-приложение для сервиса заметок с авторизацией пользователей.

## Описание проекта

Проект представляет собой backend для сервиса личных заметок. Каждый пользователь имеет доступ только к своим заметкам, работа с которыми возможна только после авторизации.

## Техническое задание

### 1. Авторизация

- Регистрация пользователя (email/логин + пароль)
- Вход в систему (аутентификация)
- Хранение паролей в защищённом виде (хэширование)
- Выдача и проверка токена доступа (например, JWT) для последующих запросов
- Разграничение доступа: пользователь видит и может изменять только свои заметки

### 2. Заметки

Заметка — это единица контента, содержащая текст.

Реализовать CRUD-операции над заметками:

| Операция | Описание |
|---|---|
| Создание | Пользователь создаёт новую заметку (текст) |
| Чтение | Пользователь получает список своих заметок / конкретную заметку |
| Редактирование | Пользователь изменяет текст существующей заметки |
| Удаление | Пользователь удаляет свою заметку |

**Ограничение:** пользователь может создавать, читать, редактировать и удалять только заметки, принадлежащие ему.

### 3. Модель данных (базовая)

**User**
- Id
- FirstName
- Name
- Email
- PasswordHash

**Note**
- Id
- OwnerId
- Title
- Text
- Created 

## Roadmap (будущие возможности)

Функциональность, которая **не входит** в текущий этап разработки, но должна учитываться при проектировании архитектуры (модель данных, права доступа), чтобы её можно было добавить без переписывания ядра системы.

### Совместный доступ к заметкам

- Возможность поделиться заметкой с другим пользователем
- Гибкая настройка прав доступа для каждого пользователя, с которым расшарена заметка:
  - право на чтение
  - право на редактирование
  - право на удаление

### Группы пользователей

- Создание групп пользователей
- Назначение прав доступа на уровне группы (для каждого участника группы отдельно)
- Возможность скрывать отдельные заметки от конкретных пользователей внутри группы
- Прочие механизмы управления видимостью и правами в рамках группы (уточняется по мере проработки)
